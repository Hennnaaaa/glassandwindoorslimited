# Image Credits / Provenance

This file records the source of every photo used on the Glass and Windoors Limited
website, and is kept as an internal provenance record for the business owner — not
required for legal attribution, but useful for knowing what can be swapped later and why.

None of these images were taken from, or derived from, any competitor website
(including dgsgroup.co.uk).

**Every image path used on the site is unique — no file is reused across two different
pages/sections.** Verified programmatically (see the check at the bottom of this file);
re-run it after adding or reassigning any image.

## Notes

- **Every per-product card grid site-wide sizes its image box to that exact photo's aspect
  ratio** (homepage services grid, /services listing cards, sealed-units hub and homepage
  spotlight grids, "other sealed unit types" and "you might also need" cross-link cards,
  Completed Projects grid) — no fixed-height box + `object-cover` cropping remains anywhere
  a specific named product/project is being represented. The only intentional exceptions are
  full-bleed backgrounds that must fill an arbitrary viewport shape (the homepage hero photos)
  and general multi-photo browsing grids where thumbnails are expected (the /gallery page's
  square grid and the homepage's "Recent Work" bento grid) — both still use `object-cover` in
  a fixed box, which is normal for a "browse many photos" UI, not a per-product photo.
- **The homepage's main focus is now Sealed Units**, per explicit request: a dedicated
  `SealedUnitsSpotlight` section sits directly after the trust bar, before the general
  services grid — the first real content a visitor sees below the hero. It shows all 7
  sealed-unit types with their own images and links to `/services/sealed-units`.
- **Real project photography replaced stock photos for six main services** (casement
  windows, tilt & turn, sliding doors, bi-fold doors, composite doors, roof lanterns) —
  per feedback that the original Pexels stock photos "looked unreal." These now use the
  owner's own installation photos, pulled from a sibling project on the same machine
  (`C:\Users\AAA LAPTOP\glazingzz\public\images\services\`), which is the owner's own prior
  glazing-company site and photography, not a competitor's. Most source photos are square
  (1200×1200, Instagram-style crops) rather than landscape; since every cover image is sized
  to its own exact aspect ratio (see `src/data/imageDimensions.js`), a square photo displays
  in a square panel with zero crop and zero empty space — "no crop / no gap" was always the
  real requirement, not "landscape-only."
- **Every sealed-unit sub-type has its own dedicated images now — nothing borrowed from
  another page.** Earlier drafts had several sub-types reusing another service's exact
  cover/gallery files (e.g. Acoustic & Laminated Glass showing the same photos as the Tilt &
  Turn Windows page). Per explicit feedback that images must never repeat across different
  parts of the site, every sub-type was given fresh, previously-unused photos — mostly
  additional (never-used-elsewhere) gallery shots from the same glazingzz categories, so nothing
  duplicates a photo already shown on that category's own main service page.
- **The three double-glazed-decorative*.jpg files** all came from one folder named "double
  glazed in sealed units." They were initially assigned to Obscure Glass based on their visual
  content (leaded/bevelled decorative glass), then reassigned to Double Glazed Units per the
  owner's explicit correction, since that's what the source folder was actually for.
- **services/sealed-units/{cover,gallery-1,gallery-2}.jpg are hub-page-only.** They appear
  on `/services/sealed-units` (the category overview) and are not reused by any individual
  sealed-unit type.
- **Manufacturer-branded diagrams — logo cropped out, per the business owner's explicit
  direction.** The owner shared four glass-construction diagrams for the sealed-units pages.
  Two of them (`Desktop/triple glass.jpg` — spacer bar cross-section, `Desktop/tripleglazed.jpeg`
  — unit cutaway) carried a real glass manufacturer's ("PRESSGLASS") logo and wordmark in the
  bottom-right corner. Publishing them as-is risked implying a partnership/endorsement that
  doesn't exist and used that company's branded marketing artwork. Given the choice between
  skipping them, cropping them, or commissioning original illustrations, the owner chose to
  crop: each was cropped to the top 1290px of a 1920×1440 source (verified the crop line sits
  below every text label, removing only the empty-background strip the logo sat in). No
  version with the logo intact was ever published. The unbranded diagram from that original
  set of four (`Desktop/ascoutic glass.jpeg`, no visible logo) was used unedited as
  services/sealed-units/acoustic-glass.jpg. Triple Glazed Units' cover was later replaced
  with a real bay-window photo, and the gallery expanded to include the two cropped PRESSGLASS
  diagrams *plus* three more diagrams from a new "tripple glazed" desktop folder (four images
  total there: one real photo used as cover, three generic construction diagrams used as
  gallery, none logo-branded) — per explicit instruction to keep the original two cropped
  diagrams alongside the new ones rather than replace them. Triple Glazed Units' gallery is
  therefore larger (5 images) than every other sealed-unit sub-type (2 images each). The three
  "tripple glazed" folder images were generically named ("images.jpg", "images (1).jpg" etc.,
  consistent with a reverse-image/Google Images download) rather than supplied as the owner's
  own photography — worth bearing in mind if their original source or licence ever needs
  checking.
- **services/tilt-turn-windows/cover.jpg** shows a window mechanically opened in the tilt
  position (top-hinged, swung inward) — the clearest available illustration of the tilt &
  turn opening mechanism.
- The homepage's "Recent Work" bento grid (`GalleryPreview.jsx`) and the services grid/cards
  intentionally show a service's own designated cover image as its own promotional teaser —
  that's normal "this card links to that page and previews it" behaviour, not the kind of
  cross-category duplication addressed above.
- Pexels images are used under the [Pexels License](https://www.pexels.com/license/): free
  for commercial and non-commercial use, no attribution required, modification permitted.
  Downloaded directly from Pexels' CDN (`images.pexels.com`) at 1600px (hero/about) or
  1200px (services) width, verified as valid JPEGs before committing.

## Verifying no duplicates

```bash
node -e "
const fs = require('fs');
const c = fs.readFileSync('src/data/services.js', 'utf8');
const matches = [...c.matchAll(/\"(\/images\/[^\"]+)\"/g)].map(m => m[1]);
const counts = {};
for (const m of matches) counts[m] = (counts[m] || 0) + 1;
const dupes = Object.entries(counts).filter(([,n]) => n > 1);
console.log(dupes.length ? dupes : 'No duplicates.');
"
```
